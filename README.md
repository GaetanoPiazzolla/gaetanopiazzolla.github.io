```shell
bundle exec jekyll serve
```

### Medium Export

Convert a Jekyll post to Medium-ready HTML, opens it in the browser:

```shell
python3 medium_export.py _posts/2026-30-07-modulith-gcp-pubsub.md
```

Click **"📋 Copy All for Medium"** → paste into Medium's editor. 
No dependencies required.

The only things left out are the image captions and the syntax highlighting for the various code snippets.
